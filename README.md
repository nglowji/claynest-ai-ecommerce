# ClayNest AI

A planned handmade ceramics e-commerce platform with an AI shopping assistant, a RAG knowledge base, and business analytics.

## Project status

Planning stage. Application implementation has not started.

## Planned stack

- Frontend: React and TypeScript
- API: Python and FastAPI
- Database: PostgreSQL with SQLAlchemy, Alembic, and pgvector
- Product language: Vietnamese
- Currency: VND

## Planned MVP

- Product discovery and checkout for handmade ceramics
- AI-assisted shopping and ceramic-care guidance
- Administration for products, orders, and content
- Sales analytics based on actual application data

Local specification documents are excluded from version control. Only README Markdown files are tracked.
